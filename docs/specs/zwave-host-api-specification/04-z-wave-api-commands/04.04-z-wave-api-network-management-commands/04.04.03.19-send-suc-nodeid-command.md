# 4.4.3.19 Send SUC NodeID Command

This command is used to trigger the transfer of SUC/SIS NodeID from Primary/Static controller to a given controller NodeID. The Send SUC NodeID Command Identifier is 0x57.

Frame flow

[The frame flow for this command is an Acknowledged frame with response and callback .](../../03-interface-communication/03.03-command-frame-flows.md#335-acknowledged-frame-with-response-and-callback)

1. Initial data frame (host → Z-Wave Module)

[The initial data frame MUST be formatted according to Table 4.155 .](04.04.03.19-send-suc-nodeid-command.md#44319-send-suc-nodeid-command)

Table 4.155: Send SUC NodeID Command - Initial data frame

| byte\bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 4 | Z-Wave API Command ID = 0x57 |  |  |  |  |  |  |  |
| 5/5..6 | NodeID |  |  |  |  |  |  |  |
| 6/7 | Tx Options |  |  |  |  |  |  |  |
| 7/8 | Session identifier |  |  |  |  |  |  |  |
