# 4.9.4 End Node Send Data Multicast Command

This command is used to transmit a data buffer to a list of Z-Wave nodes (i.e., S2 Multicast frame).

The End Node Send Data Multicast Command Identifier is 0x0F. This command shall only be supported [by End Node library types (refer to Table 4.36 ).](../04.03-z-wave-capability-api-commands/04.03.10.03-2-response-data-frame-z-wave-module-host.md#43103-2-response-data-frame-z-wave-module-host)
