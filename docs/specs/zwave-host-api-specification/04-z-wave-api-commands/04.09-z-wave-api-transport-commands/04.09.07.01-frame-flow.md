# 4.9.7.1 Frame flow

[The frame flow for this command is an Acknowledged frame .](../../03-interface-communication/03.03-command-frame-flows.md#332-acknowledged-frame)

If a host application aborts an ongoing transmission, the Z-Wave API Module MUST still issue a 3. [callback data frame for the ongoing transmission. This is illustrated in Figure 4.21 . A Z-Wave API](04.09.07.01-frame-flow.md#4971-frame-flow) Module MUST ignore this command if it is received when no transmission is ongoing.
