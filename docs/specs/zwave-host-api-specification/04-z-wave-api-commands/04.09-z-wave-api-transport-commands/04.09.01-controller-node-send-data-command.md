# 4.9.1 Controller Node Send Data Command

This command is used to transmit contents of a data buffer to a single node or all nodes (broadcast). The Controller Node Send Data Command Identifier is 0x13.

[This command MUST only be supported by controller Z-Wave library types (refer to Table 4.36 ).](../04.03-z-wave-capability-api-commands/04.03.10.03-2-response-data-frame-z-wave-module-host.md#43103-2-response-data-frame-z-wave-module-host)
