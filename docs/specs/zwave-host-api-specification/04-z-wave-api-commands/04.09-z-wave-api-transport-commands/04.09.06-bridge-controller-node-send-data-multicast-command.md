# 4.9.6 Bridge Controller Node Send Data Multicast Command

This command is used to transmit a data buffer to a list of Z-Wave nodes (i.e., Multicast frame). The Bridge Controller Node Send Data Multicast Command Identifier is 0xAB.

This command MUST only be supported by Z-Wave API Module using the Controller Bridge library [types (refer to Table 4.36 ).](../04.03-z-wave-capability-api-commands/04.03.10.03-2-response-data-frame-z-wave-module-host.md#43103-2-response-data-frame-z-wave-module-host)
