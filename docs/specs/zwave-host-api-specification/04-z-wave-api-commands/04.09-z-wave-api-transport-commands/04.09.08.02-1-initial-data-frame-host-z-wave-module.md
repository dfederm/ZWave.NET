# 4.9.8.2 1. Initial data frame (host → Z-Wave Module)

[The initial data frame MUST be formatted according to Table 4.241 .](04.09.08.02-1-initial-data-frame-host-z-wave-module.md#4982-1-initial-data-frame-host-z-wave-module)

Table 4.241: Send Test Frame Command - Initial data frame

| byte\bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 4 | Z-Wave API Command ID = 0xBE |  |  |  |  |  |  |  |
| 5/5..6 | NodeID |  |  |  |  |  |  |  |
| 6/7 | Powerlevel |  |  |  |  |  |  |  |

NodeID (8/16 bits)

[This field is used to advertise the NodeID of the node where the test frame is sent to.](../04.03-z-wave-capability-api-commands/04.03.15.09-z-wave-api-setup-set-nodeid-base-type-sub-command.md#43159-z-wave-api-setup-set-nodeid-base-type-sub-command)

[This field MUST be encoded according to the configured NodeID base Type. Refer to Z-Wave API Setup Set NodeID Base Type Sub Command and Table 4.64 .](../04.03-z-wave-capability-api-commands/04.03.15.09-z-wave-api-setup-set-nodeid-base-type-sub-command.md#43159-z-wave-api-setup-set-nodeid-base-type-sub-command)

Powerlevel (8 bits)

This field is used to advertise the power level which the Z-Wave module shall use for the RF transmission of [the test frame. This field MUST comply with the format indicated in Set RF Power Level Command](../04.08-z-wave-api-miscellaneous-commands/04.08.09-set-rf-power-level-command.md#489-set-rf-power-level-command) initial data frame section.
