RSSI (2 or 3 bytes)

The RSSI fields are used to indicate the measured RSSI.

If the Z-Wave Module operates on a 2 channel RF Profile, RSSI CH0, and RSSI CH1 field MUSTTt contain the RSSI values of the first and second channel.

If the Z-Wave Module operates on a 3 channel RF profile, all three RSSI fields MUST contain RSSI values.
