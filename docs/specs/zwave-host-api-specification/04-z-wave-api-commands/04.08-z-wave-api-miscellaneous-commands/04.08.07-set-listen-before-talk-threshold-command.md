# 4.8.7 Set Listen Before Talk Threshold Command

This command is used to to set the “Listen Before Talk” RSSI threshold that controls at what RSSI level a Z-Wave node will refuse to transmit because of noise. The default threshold value is set to a value corresponding to the RF regulatory requirements in the specific country. The Set Listen Before Talk Threshold Command Identifier is 0x3C.
