# 4.8.8.3 2. Response data frame (Z-Wave Module → host)

[A Z-Wave module MUST return a response frame formatted according to Table 4.207](04.08.08.03-2-response-data-frame-z-wave-module-host.md#4883-2-response-data-frame-z-wave-module-host)

Table 4.207: Set Rf Receive Mode Command - Response data frame

| byte\bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 4 | Z-Wave API Command ID = 0x10 |  |  |  |  |  |  |  |
| 5 | Status |  |  |  |  |  |  |  |

Status (8 bits)

This field is used to advertise information about the status of the Set RF Receive Mode operation. The feild MUST encoded according to:

• 0x01, If the operation was successfull.

• 0x00, If the operation was not successfull.
