# 4.8.8 Set RF Receive Mode Command

This command is used to to power down the RF when not in use e.g., expects nothing to be received. It can also be used to set the RF into receive mode. This functionality is useful in battery powered Z-Wave nodes. The RF is automatic powered up when transmitting data.

The Set RF Receive Mode Command Identifier is 0x10.
