# 4.3.3 Set Application Node Information Command Classes Command

This command is used to configure the list of supported Command Classes for each of the following inclusion states:

• Not included in a network

• Included: Non-securely supported

• Included: Securely supported

The Set Application Node Information Command Classes Command Identifier is 0x0C. This command [MUST only be supported by a Z-Wave Module that employs End Node libraries (Refer to Get Library Version Command - Library Type encoding ).](04.03.10.03-2-response-data-frame-z-wave-module-host.md#43103-2-response-data-frame-z-wave-module-host)
