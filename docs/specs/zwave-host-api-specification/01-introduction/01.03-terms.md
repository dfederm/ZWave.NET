# 1.3 Terms

This document describes mandatory and optional aspects of the required compliance of a Z-Wave prod- uct to the Z-Wave standard.

[The guidelines outlined in RFC 2119 with respect to key words used to indicate requirement levels are](https://tools.ietf.org/html/rfc2119.html) followed. Essentially, the key words “MUST”, “MUST NOT”, “REQUIRED”, “SHALL”, “SHALL NOT”, “SHOULD”, “SHOULD NOT”, “RECOMMENDED”, “MAY”, and “OPTIONAL” in this doc- [ument are to be interpreted as described in RFC 2119 .](https://tools.ietf.org/html/rfc2119.html)
