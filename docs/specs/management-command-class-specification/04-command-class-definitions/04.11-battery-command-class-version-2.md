# 4.11 Battery Command Class, version 2

This Command Class is used to request and report the battery types, status and levels of a given device.

## 4.11.1 Compatibility considerations

The following commands has been extended to query status and levels of a battery:

 [Battery Get Command](04.11-battery-command-class-version-2.md#4112-battery-get-command)  [Battery Report Command](04.11-battery-command-class-version-2.md#4113-battery-report-command)

The following commands are added for requesting the current health of the battery.

 [Battery Health Get Command](04.11-battery-command-class-version-2.md#4114-battery-health-get-command)  [Battery Health Report Command](04.11-battery-command-class-version-2.md#4115-battery-health-report-command)

## 4.11.2 Battery Get Command

This command is used to request both the level of a battery and its status.

[The Battery Report Command MUST be returned in response to this command](04.11-battery-command-class-version-2.md#4113-battery-report-command)

This command MUST NOT be issued via multicast addressing. A receiving node MUST NOT return a response if this command is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.

## 4.11.3 Battery Report Command

This command is used to report the level and status of a battery-operated device.

Battery Level (8 bits)

This field is used to report the percentage indicating the battery level.

This field MUST be in the range 0x00..0x64 or set to 0xFF.

The value 0xFF MUST indicate a low-battery warning and this notification SHOULD only be sent as an unsolicited Report to the Lifeline destinations.

Values in the range 0x00..0x64 MUST indicate the battery percentage level from 0 to 100%.

The percentage level of 0% represents the lowest operational voltage of the device. For example; if the device can no longer operate properly below a battery voltage of 2.2V, the device should report 0% level when the battery voltage reaches 2.2V.

Battery Charging Status (2 bits)

The field describes the charging status of a battery if the rechargeable flag field is 1. The field MUST be [encoded according to Table 9.](04.11-battery-command-class-version-2.md#4113-battery-report-command)

If the Rechargeable flag field is set to 0, the battery charging status value MUST be 0x00.

Table 9, Charging status notification values: Battery Command Class

| Value | Description |
| --- | --- |
| 0x00 | Discharging |
| 0x01 | Charging |
| 0x02 | Maintaining |

This field indicates if the battery is rechargeable or not.

If the battery is rechargeable this field MUST be set to 1. If the battery is not rechargeable, the field value MUST set to 0.

Back-up battery (1 bit)

This field is used to illustrate if the battery is utilized for back-up purposes of a mains powered connected device.

If the battery is used for back-up purposes the field MUST be set to 1. CC:0080.02.03.11.005 If battery is the primary means of power and is not for back-up, this field MUST set to 0.

Overheating (1 bit)

This field is used to indicate if overheating is detected at the battery.

The value 1 MUST indicate that the battery is overheating The value 0 MUST indicate that the battery is operating within the normal temperature range.

Low fluid (1 bit)

This field is used to indicate if the battery fluid is low and should be refilled.

The value 1 MUST indicate that the battery fluid is low. The value 0 MUST indicate that the battery fluid is within the normal range and no maintenance is required.

Replace/recharge status bitmask (2 bits)

This field is used to indicate if the battery needs to be recharged or replaced.

Bit 0 set to 1 MUST indicate that the battery MUST be replaced/recharged soon. Bit 1 set to 1 MUST indicate that the battery MUST be replaced/recharged now.

If bit 1 is set to 1, bit 0 MUST also be set to 1.

Disconnected (1 bit)

This field is used to indicate if the battery is currently disconnected or removed from the node.

The value 1 MUST indicate that the battery is disconnected and the node is running on an alternative power source. The value 0 MUST indicate that the battery correctly connected to the node.

If this field is set to 1, the Battery Level field MUST be set to 0x00.

Maximum Capacity (8 bits)

This field is used to report the percentage indicating the maximum capacity of the battery.

This field MUST be in the range 0x00..0x64 or set to 0xFF. If the maximum capacity of the battery is unknown the value MUST set to 0xFF.

Values in the range 0x00..0x64 MUST indicate the maximum capacity of the battery in the percentage level from 0 to 100%.

Precision (3 bits)

This field is used to indicate how many decimal places are included in the Battery Temperature field. For example, the Battery Temperature field set to 1025 with the Precision field set to 2 MUST be interpreted as 10.25.

Scale (2 bits)

The scale field indicates the scale used for the battery temperature value. This field MUST be encoded [according to Table 10](04.11-battery-command-class-version-2.md#4115-battery-health-report-command)

Table 10, Battery Health Report: Scale field encoding

| Value | Description |
| --- | --- |
| 0x00 | Celsius |
| 0x01..0x03 | Reserved |

Size (3 bits)

The size field indicates the number of bytes used for the battery temperature value. This field MUST be set to 0, 1, 2 or 4.

The value 0 MUST indicate that the battery temperature is unknown. In this case, the Scale and Precision fields MUST be set to 0 and the Battery Temperature field MUST be omitted.

Values 1, 2 and 4 MUST indicate the length in bytes of the Battery Temperature field.

Battery Temperature (N bytes)

This field advertises the temperature of the battery.

The length of this field in bytes MUST be according to the Size field.

The first byte MUST be the most significant byte.

This field MUST be encoded using signed representation and comply with Signed field encoding [representation (Reference: Table 10 in [16]).](04.48-z-wave-plus-info-command-class-version-2.md#4484-z-wave-plus-info-report-command)
