# 2 Introduction

Commands classes are divided in four categories:

 [Application Command Classes [16]](../04-command-class-definitions/04.48-z-wave-plus-info-command-class-version-2.md#4484-z-wave-plus-info-report-command)  Management Command Classes  [Transport-Encapsulation Command Classes [15]](../04-command-class-definitions/04.48-z-wave-plus-info-command-class-version-2.md#4484-z-wave-plus-info-report-command)  [Network-Protocol Command Classes [17]](../04-command-class-definitions/04.48-z-wave-plus-info-command-class-version-2.md#4484-z-wave-plus-info-report-command)

[The list of defined Command Classes with their associated category is available in [14].](../04-command-class-definitions/04.48-z-wave-plus-info-command-class-version-2.md#4484-z-wave-plus-info-report-command)

This document describes the Command Classes designed for node management specific purposes. Management command classes are used for service and capabilities discovery, as well as battery management or node associations.
