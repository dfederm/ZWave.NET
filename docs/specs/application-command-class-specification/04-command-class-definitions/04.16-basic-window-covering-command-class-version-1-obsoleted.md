# 4.16 Basic Window Covering Command Class, version 1 [OBSOLETED]

THIS COMMAND CLASS HAS BEEN OBSOLETED

New implementations MUST NOT support this command class.

New window covering device implementations SHOULD support the Window Covering Command Class.

This section contains Commands that may be used to control a Basic Window Covering Command Class.

## 4.16.1 Basic Window Covering Start Level Change Command

This command is used to start moving drapes, shades, blinds in a given direction. The speed of the movement is implementation specific.

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |

| Command Class = COMMAND CLASS BASIC WINDOW COVERING _ _ _ _ |  |  |  |  |  |  |  |
| Command = BASIC WINDOW COVERING START LEVEL CHANGE _ _ _ _ _ |  |  |  |  |  |  |  |
| Reserved | Open/ Close | Reserved |  |  |  |  |  |

Open/Close (1 bit)

If the Open/Close bit is set to 0 the window covering SHOULD open. If field is set to 1 the window covering SHOULD close.

Reserved

This field MUST be set to 0 by a sending node and MUST be ignored by a receiving node.
