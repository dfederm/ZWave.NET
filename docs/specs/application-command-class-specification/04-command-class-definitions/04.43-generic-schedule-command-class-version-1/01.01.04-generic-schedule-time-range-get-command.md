# 1.1.4 Generic Schedule Time Range Get Command

This command is used to request the configuration of a Time Range ID for a supporting node.

[The Generic Schedule Time Range Report Command MUST be returned in response to this command.](01.01.05-generic-schedule-time-range-report-command.md#115-generic-schedule-time-range-report-command)

This command MUST NOT be issued via multicast addressing. A receiving node MUST NOT return a response if this command is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.

Time Range ID (16 bits)

This field is used to specify the requested Time Range ID.

The first byte MUST carry the most significant byte of the 15 bits.

A supporting node MUST return this value in the Time Range ID [field in the returned Generic Schedule Report Command.](01.01.08-generic-schedule-report-command.md#118-generic-schedule-report-command)
