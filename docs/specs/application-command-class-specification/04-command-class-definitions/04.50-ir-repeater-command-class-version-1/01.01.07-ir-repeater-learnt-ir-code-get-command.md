# 1.1.7 IR Repeater Learnt IR Code Get Command

This command is used to request a supporting node which IR Code identifiers have a valid IR Code learnt.

This command MUST be ignored by a receiving node if it advertises 0 Number of IR Code identifiers for learning [in the IR Repeater Capabilities Report Command.](01.01.02-ir-repeater-capabilities-report-command.md#112-ir-repeater-capabilities-report-command)

[The IR Repeater Learnt IR Code Report Command MUST be returned in response to this command if it](01.01.08-ir-repeater-learnt-ir-code-report-command.md#118-ir-repeater-learnt-ir-code-report-command) was not ignored.

This command MUST NOT be issued via multicast addressing.

A receiving node MUST NOT return a response if this command is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.
