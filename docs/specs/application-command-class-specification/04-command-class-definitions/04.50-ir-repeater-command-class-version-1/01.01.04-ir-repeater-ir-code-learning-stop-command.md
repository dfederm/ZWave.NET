# 1.1.4 IR Repeater IR Code Learning Stop Command

This command is used to instruct a supporting node to stop learning an IR Code.

This command MUST be ignored by a receiving node if it advertises 0 Number of IR Code identifiers for learning [in the IR Repeater Capabilities Report Command.](01.01.02-ir-repeater-capabilities-report-command.md#112-ir-repeater-capabilities-report-command)

A supporting node MUST stop learning IR Code if a learning process was ongoing when this command is received.

[A supporting node MUST return a IR Repeater IR Code Learning Status Command in response to this](01.01.05-ir-repeater-ir-code-learning-status-command.md#115-ir-repeater-ir-code-learning-status-command) command.
