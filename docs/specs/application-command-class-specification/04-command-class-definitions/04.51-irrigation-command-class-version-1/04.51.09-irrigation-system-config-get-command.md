# 4.51.9 Irrigation System Config Get Command

This command is used to request a receiving node about its current irrigation system configuration.

[The Irrigation System Config Report Command MUST be returned in response to this command.](04.51.10-irrigation-system-config-report-command.md#45110-irrigation-system-config-report-command)

This command MUST NOT be issued via multicast addressing.

A receiving node MUST NOT return a response if this command is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.
