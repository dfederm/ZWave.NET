# 3.7 Z-Wave Hardware Timers

The 200/300/400/500 Series Z-Wave SoCs have a number of hardware timers/counters. Some are reserved by the protocol and others are free to be used by the application as shown in the table below:

Table 1. 200/300/400/500 Series Z-Wave SoCs Hardware Timer Allocation

|  | 200 Series | 300 Series | 400 Series | 500 Series |
| --- | --- | --- | --- | --- |
| TIMER0 | Protocol system clock | Protocol system clock | Available for the application | Available for the application |
| TIMER1 | Available for the application | Available for the application | Used by the protocol | Available for the application |
| GPTIMER | Available for the application | Available for the application | Available for the application | Available for the application |

The TIMER0 and TIMER1 are standard 8051 timers/counters.
