# 2.3 Key words to Indicate Requirement Levels

[The guidelines outlined in IETF RFC 2119 “Key words for use in RFCs to Indicate Requirement Levels” [17] apply:](../08-references.md#8-references) The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in RFC 2119.
