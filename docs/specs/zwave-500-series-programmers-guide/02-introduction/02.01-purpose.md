# 2.1 Purpose

The Application Programming Guide gives guidance for developing Z-Wave application programs, which use the Z-Wave application programming interface (API) to access the Z-Wave Protocol services and [500 Series SoC resources. For host processor application development using the serial API, refer also to [2].](../08-references.md#8-references)

[For details about working in the 500 Series environment, refer to [14].](../08-references.md#8-references)

The document is also an API reference guide for programmers.
