# 4.3.12.12 ZW_ADC_auto_zero_set

void ZW_ADC_auto_zero_set(BYTE bAzpl)

This function MAY be used to define the ADC sampling period. Default value is ADC_AZPL_128. It is RECOMMENDED to use longer sampling periods for high impedance analog inputs.

Defined in: ZW_adcdriv_api.h

Parameters:

bAzpl ADC_AZPL_1024 Set the autozero period to 128us RECOMMENDED for high impedance analog inputs

ADC_AZPL_512 Set the autozero period to 64us RECOMMENDED for medium to high impedance analog inputs.

ADC_ZPL_256 Set the autozero period to 32us RECOMMENDED for medium to low impedance analog inputs.

ADC_ZPL_128 Set the autozero period to 16us RECOMMENDED for low impedance analog inputs.

Serial API (Not supported)
