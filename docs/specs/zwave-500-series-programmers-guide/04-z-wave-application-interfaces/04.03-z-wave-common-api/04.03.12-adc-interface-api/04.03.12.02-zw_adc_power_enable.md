# 4.3.12.2 ZW_ADC_power_enable

void ZW_ADC_power_enable(BYTE boEnable)

This function SHOULD be used to control when the ADC unit is powered. ADC is powered down, when the module enters sleep mode.

Calling ZW_ADC_init() will power up the ADC.

Defined in: ZW_adcdriv_api.h

Parameters:

boEnable IN TRUE Turn the ADC power on

FALSE Turn the ADC power off. The ADC will cancel any activity immediately.

Serial API (Not supported)
