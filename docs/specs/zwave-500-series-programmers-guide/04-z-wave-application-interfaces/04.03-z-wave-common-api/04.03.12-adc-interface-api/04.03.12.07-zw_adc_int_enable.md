# 4.3.12.7 ZW_ADC_int_enable

void ZW_ADC_int_enable(BYTE boEnable)

Therefore, function MAY be used to enable or disable ADC interrupt requests. If enabled, an interrupt routine MUST be defined. The ADC interrupt is disabled by default.

If ADC interrupts are enabled, the ADC interrupt flag MUST be reset by calling ZW_ADC_int_clear before returning from the interrupt routine.

Defined in: ZW_adcdriv_api.h

Parameters:

boEnable IN TRUE Enable the ADC interrupt

FALSE Disable the ADC interrupt

Serial API (Not supported)
