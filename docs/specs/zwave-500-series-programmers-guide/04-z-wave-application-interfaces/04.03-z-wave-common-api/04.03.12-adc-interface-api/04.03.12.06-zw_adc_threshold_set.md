# 4.3.12.6 ZW_ADC_threshold_set

void ZW_ADC_threshold_set(WORD wThreshold)

This function MAY be used to set the ADC threshold value. Depending on the threshold mode (set by ZW_ADC_threshold_mode_set) , the threshold value is used to trigger an interrupt when the sampled value is above/equal or below/equal the threshold value.

The API ZW_ADC_ threshold_mode_set MUST be called before calling this function.

Defined in: ZW_adcdriv_api.h

Parameters:

wThreshold IN 8-bit resolution Threshold value range is 0 .. 255

12-bit resolution Threshold value range is 0 .. 4095

Serial API (Not supported)
