# 4.3.19.9 ZW_IR_learn_data

void ZW_IR_learn_data(void)

ZW_IR_learn_data clears the variable and starts the IR Controller in Rx/learn mode. Use ir_rx_flag ZW_IR_disable to cancel on ongoing learn process.

Defined in: ZW_infrared_api.h

Serial API (Not supported)
