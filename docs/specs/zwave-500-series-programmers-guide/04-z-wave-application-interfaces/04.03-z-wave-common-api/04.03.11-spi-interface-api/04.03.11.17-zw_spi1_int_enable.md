# 4.3.11.17 ZW_SPI1_int_enable

void ZW_SPI1_int_enable(BYTE boEnable)

Call will enable or disable the SPI1 interrupt. If enabled an interrupt routine must be defined. Default is the SPI1 interrupt is disabled. If the SPI1 interrupt is used, then the SPI1 interrupt flag should be reset before returning from the NOTE: interrupt routine by calling ZW_SPI1_int_clear.. Defined in: ZW_spi_api.h

Parameters:

boEnable IN TRUE Enables the SPI1 interrupt.

FALSE Disables the SPI1 interrupt.

Serial API (Not supported)
