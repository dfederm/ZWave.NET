# 4.3.2.23 ZW_GetTxTimer

void ZW_GetTxTimer(BYTE bChannel, DWORD *dwTxTime)

This function gets the protocols internal tx timer for the specified channel. The returned value is in milli seconds from the last call to ZW_ClearTxTimers(). The tx timers are updated by the protocol exery time a frame is send.

Defined in: ZW_basis_api.h

Parameters:

bChannel IN The channel to get the tx timer from. Valid channels are 0, 1 and 2

dwTxTime OUT The time the transmitter has been active since the last reset or call to ZW_ClearTxTimers()

Serial API:

HOST->ZW: REQ | 0x38

ZW->HOST: RES | 0x38 | TxTimeChannel0 | TxTimeChannel1 | TxTimeChannel2
