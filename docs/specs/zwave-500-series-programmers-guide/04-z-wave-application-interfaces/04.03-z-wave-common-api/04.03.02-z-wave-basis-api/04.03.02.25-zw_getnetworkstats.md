# 4.3.2.25 ZW_GetNetworkStats

void ZW_GetNetworkStats(S_NETWORK_STATISTICS *sNetworkStats)

This function retrieves the current Network Statistics as collected by the Z-Wave protocol. The Z-Wave protocol will continuesly update any Network Statistics counter until it reaches 65535, which then [indicates that the specific counter has reached 65535 or more occurrences. The Network Statistics counters are cleared either on module startup or by calling ZW_ClearNetworkStats().](04.03.02.26-zw_clearnetworkstats.md#43226-zw_clearnetworkstats)
