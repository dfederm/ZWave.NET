# 4.3.2.6 ZW_Random

BYTE ZW_Random( void )

Macro: ZW_RANDOM()

This function implements a simple pseudo-random number generator that generates a sequence of numbers, the elements of which are approximately independent of each other. The same sequence of pseudo-random numbers will be repeated in case the module is power cycled.

An application MAY use this function for implementing random behavior, e.g., when multiple nodes respond to a multicast message. The Z-Wave protocol MAY also use this function for random backoff, etc. Due to its simple nature, an application MUST NOT use this function for obtaining random values for security key calculation and encryption.

Defined in: ZW_basis_api.h

Return value:

BYTE Random number (0 – 0xFF)

Serial API

HOST->ZW: REQ | 0x1D

ZW->HOST: RES | 0x1D | rndNo
