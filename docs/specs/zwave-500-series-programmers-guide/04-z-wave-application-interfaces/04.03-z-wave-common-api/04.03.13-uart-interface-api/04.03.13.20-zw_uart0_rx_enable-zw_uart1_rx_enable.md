# 4.3.13.20 ZW_UART0_rx_enable / ZW_UART1_rx_enable

void ZW_UART0_rx_enable(BYTE bState) / void ZW_UART1_rx_enable(BYTE bState)

This function is used to enable or disable the UARTx Rx function in runtime. Use the function ZW_UARTx_init to set the initial state of the Rx function. When enabling the UARTx Rx function the UARTx Rx pin will become an intput.

Defined in: ZW_uart_api.h

Parameters:

bState IN TRUE UARTx Rx enabled

FALSE UARTx Rx disabled

Serial API (Not supported)
