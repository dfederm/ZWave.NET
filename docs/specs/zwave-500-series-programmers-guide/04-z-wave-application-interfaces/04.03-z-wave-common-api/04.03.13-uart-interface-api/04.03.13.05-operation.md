# 4.3.13.5 Operation

Data to be transmitted is written to a UART data register, one byte at the time and data received is read from a SPI data register one byte at the time. A UART interrupt can be issued when the UART controller has transferred a byte on the UART interface. This API supports transmissions of either a single byte, or a data string. The received characters are read by the application one-by-one.
