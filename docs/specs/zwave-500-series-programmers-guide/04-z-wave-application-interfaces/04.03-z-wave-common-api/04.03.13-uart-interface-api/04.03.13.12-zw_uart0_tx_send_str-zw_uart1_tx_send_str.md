# 4.3.13.12 ZW_UART0_tx_send_str / ZW_UART1_tx_send_str

void ZW_UART0_tx_send_str(BYTE* pStr) / void ZW_UART1_tx_send_str(BYTE* pStr)

Transmit a null terminated string over UARTx. The null data is not transmitted. This function waits until UARTx transmitter is idle before it sends the first data byte data. The function does not wait until the last data byte has been sent.

See also: [ZW_UART0_tx_send_num / ZW_UART1_tx_send_num](04.03.13.11-zw_uart0_tx_send_num-zw_uart1_tx_send_num.md#431311-zw_uart0_tx_send_num-zw_uart1_tx_send_num)
