# 4.3.14.4 ZW_TIMER0_INT_ENABLE / ZW_TIMER1_INT_ENABLE

ZW_TIMERx_INT_ENABLE(BYTE bState)

This macro SHOULD be used to enable or disable the Timer0/Timer1 interrupt.

Defined in: ZW_appltimer_api.h

Parameters:

bState IN TRUE Mode 0-2: TIMER0/TIMER1 interrupt is enabled Mode 3: TIMER0/TIMER1 high counter interrupt is enabled

FALSE Mode 0-2: TIMER0/TIMER1 interrupt is disabled Mode 3: TIMER0/TIMER1 high counter interrupt is disabled

Serial API (Not supported)
