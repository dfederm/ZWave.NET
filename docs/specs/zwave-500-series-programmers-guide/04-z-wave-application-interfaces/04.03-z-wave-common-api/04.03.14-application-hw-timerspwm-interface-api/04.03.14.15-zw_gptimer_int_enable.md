# 4.3.14.15 ZW_GPTIMER_int_enable

void ZW_GPTIMER_int_enable(BYTE bState)

This function SHOULD be used to enable or disable the GPTimer interrupt.

[The application designer MUST declare an Interrupt Service Routine (ISR) to handle the GP Timer interrupt. The ISR MUST use the ISR number INUM_GP_TIMER as declared in section 3.9.](../../../03-z-wave-software-architecture/03.09-interrupt-service-routines.md#39-interrupt-service-routines)

Defined in: ZW_appltimer_api.h

Parameters:

bState IN TRUE enable GPTimer interrupt

FALSE disable GPTimer interrupt

Serial API (Not supported)
