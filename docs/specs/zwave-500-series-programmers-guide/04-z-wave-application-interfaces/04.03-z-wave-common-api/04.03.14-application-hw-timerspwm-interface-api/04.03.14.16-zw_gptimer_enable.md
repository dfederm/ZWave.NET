# 4.3.14.16 ZW_GPTIMER_enable

void ZW_GPTIMER_enable(BYTE bState)

This function SHOULD be used to enable or disable the GPTimer. Disabling the GPTimer also clears the interrupt flag and resets the GPTimer counters.

Defined in: ZW_appltimer_api.h

Parameters:

bState IN TRUE enable GPTimer.

FALSE disable GPTimer.

Serial API (Not supported)
