# 4.3.14.17 ZW_GPTIMER_pause

void ZW_GPTIMER_pause(BYTE bState)

This function MAY be used to control the GPTimer pause state. When entering the pause state, the GPTimer counters stops counting. When leaving the pause state, the counters will start counting from the state they were in when the pause state was entered.

Defined in: ZW_appltimer_api.h

Parameters:

bState IN TRUE Enter GPTimer pause state.

FALSE Leave GPTimer pause state.

Serial API (Not supported)
