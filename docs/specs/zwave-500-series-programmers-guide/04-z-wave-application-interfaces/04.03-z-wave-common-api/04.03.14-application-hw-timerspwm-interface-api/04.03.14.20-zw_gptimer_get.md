# 4.3.14.20 ZW_GPTIMER_get

WORD ZW_GPTIMER_get(void)

This function MAY be used to query the 16 bit GPTimer counter register value. The returned value is in the range [reload_value-1;0]. As an example, if the reload value is set to 0x2A40, ZW_GPTIMER_get() will return a value in the range [0x2A3F;0].

An application SHOULD be designed to be robust if a higher value is returned, e.g. because the reload value was not correctly stored in the chip.

Defined in: ZW_appltimer_api.h

Return value:

WORD 16 bit counter value

Serial API (Not supported)
