# 4.5.9.13 Return Route Delete Command

This command is used to make a controller delete all static return routes from a slave node. Allocated return routes can only be removed using this command. All return routes are cleared when using this command.

After issuing this command, an application SHOULD issue Return Route Assign Commands to create return routes for all relevant associations.

[The Return Route Delete Complete Command MUST be returned in response to this command.](04.05.09.14-return-route-delete-complete-command.md#45914-return-route-delete-complete-command)

This command MUST NOT be issued via multicast addressing. A receiving node MUST ignore this command if it is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.
