# 4.5.9.9 Node Neighbor Update Request Command

This command is used to instruct a node with NodeID to perform a Node Neighbor Update operation in order to update the topology on the controller.

[The Node Neighbor Update Status Command MUST be returned in response to this command when the](04.05.09.10-node-neighbor-update-status-command.md#45910-node-neighbor-update-status-command) neighbor search is completed.

This command MUST NOT be issued via multicast addressing. A receiving node MUST ignore this command if it is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.
