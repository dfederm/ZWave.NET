# 4.5.9.3 Node Remove Command

This command is used to activate or de-activate node remove mode. The remove operation only works in direct range between the controller and the node that is to be removed.

The Node Remove mode SHOULD be disabled after a certain time to avoid removing another node unexpectedly. It is RECOMMENDED to have a timer that disables the Node Remove mode after a given time without any activity.

Node Remove mode MUST be de-activated after any removal attempt, even if interrupted.

[The Node Remove Status Command MUST be returned in response to this command unless it is](04.05.09.04-node-remove-status-command.md#4594-node-remove-status-command) ignored.

This command MUST NOT be issued via multicast addressing. A receiving node MUST ignore this command if it is received via multicast addressing. The Z-Wave Multicast frame, the broadcast NodeID and the Multi Channel multi-End Point destination are all considered multicast addressing methods.

This field MUST be set to 0 by a sending node and MUST be ignored by a receiving node.

Mode (1 byte)

This field is use to indicate to the receiving node if the node removal process must be activated or de- [activated. This field MUST comply with Table 18.](04.05.09.03-node-remove-command.md#4593-node-remove-command)

Table 18, Node Remove::Mode parameter encoding

| Value | Mode identifier | Description |
| --- | --- | --- |
| 0x01 | REMOVE NODE ANY _ _ | Remove any type of node from the network |
| 0x05 | REMOVE NODE STOP _ _ | Stop the node removal process. The command MAY be ignored if the remove process was not activated. The command MAY be ignored if network exclusion is ongoing. |

The process of removing a node is started by sending this command with Mode set to REMOVE_NODE_ANY. The removal process is complete when a Node Remove Status command with status set to NODE_REMOVE_STATUS_DONE is returned.
